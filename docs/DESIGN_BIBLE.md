# MAINXP DESIGN BIBLE

## Feeling
Premium private coach + personal command center + subtle RPG journey + original anime/alchemy transformation energy.

Not:
Tailwind tutorial / Notion clone / crypto dashboard / children’s habit app / all-dark gamer UI / identical card pile.

## Ratio
70% premium productivity/life app
20% game/RPG
10% anime/alchemy energy

## Default
Warm white, calm, elegant. The game is discovered through character, rank, gems, quest language, earned artifacts and transitions.

## Screen composition
Each page has:
1. one clear purpose
2. one dominant visual anchor
3. one dominant action
4. supporting information
5. progressive disclosure

## TODAY
Above the fold:
greeting/day
compact character + level/XP
visually dominant Main Quest
WHAT NOW? CTA
non-negotiables preview
North Star/morning cue

Do not put 14 metric cards above the fold.

## GRATITUDE
Morning and night are distinct.
Use a progressive list for 01–10 so it feels elegant rather than like a spreadsheet.
Allow voice later.
Subtle sun motif morning, moon motif night.
Reward the ritual once, not every line.

## CHARACTER
Original stylized character.
Not photorealistic. Not childish.
Character occupies ~20–30% of key progression screens.
Behavior changes appearance.

## GEMS / ALCHEMY
Faceted geometry, soft internal glow, restrained gradients, premium specular highlights.
Avoid neon overload.
Artifact screen can feel like an alchemical codex/cabinet while keeping modern typography.

## QUESTS
Main Quest strongest.
Daily Mission quieter.
Side Quest compact.
Boss Quest special frame/reward reveal.
Legendary should feel rare.

## COLOR
Purple identity.
Green health.
Blue focus.
Gold wealth/reward.
Orange challenge.
Coral people.
Teal mind.
Red only urgency.

Never use all colors equally on one screen.

## MICROINTERACTIONS
Quest check: tactile press → check stroke → +XP float 400–700ms → progress fill.
Level-up: full-screen only when rare.
Gem: one subtle shine/parallax, not endless pulse.

## COPY
French-first. Short. Serious. No exclamation spam.

Good:
“Quête principale”
“Tu es à 72% de ton objectif hebdo.”
“Il te reste 35 minutes. Fais ça maintenant.”

Bad:
“🔥🔥 LET’S GOOOO CHAMPION!!!”

## QUALITY QUESTIONS
Would this look credible next to a top-tier paid iOS app?
Is the dominant action obvious in 2 seconds?
Can 30% of these cards be removed?
Are emojis being used as lazy icons?
Is the game layer helping or distracting?
Is this visually unique to MAINXP?
