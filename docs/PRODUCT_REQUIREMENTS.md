# MAINXP — Product Requirements

> **MAINXP succeeds when the user closes the app and does something useful in
> real life.** The game's entire job is to push the person back into real life:
> open → understand what matters → act → return → record/verify → learn → level
> up. Never optimize for time-in-app.

## What MAINXP is

An **AI life operating system wrapped inside a real-life RPG**. The user's life is the
Main Quest; the game only progresses when real life progresses. It is not primarily a
habit tracker, task manager, fitness/finance app, journal, chatbot or game — those are
organs of one system.

## Central promise

> Your life is the Main Quest. You start at zero. You do not pick your character —
> your actions build your character.

The product must always help answer: *What matters? What am I building? Why?
What should I do next? Am I actually moving forward?*

## Core loop

BIO → WHY → GOALS → PROJECTS → WEEKLY TARGETS → MORNING PLAN → MAIN QUEST →
REAL ACTION → XP → AI ACCOUNTABILITY → NIGHT REVIEW → TOMORROW PREP →
WEEKLY REVIEW → AI LEARNS → BETTER PLAN → CHARACTER EVOLVES

## Non-negotiable product rules

1. **Start at zero** — bio informs the AI, never awards XP (see XP_SYSTEM.md).
2. **Earned identity** — titles/archetypes are earned from evidence, never chosen or sold.
3. **No shame** — coach uses evidence and numbers, never judgment (COACH_SYSTEM.md).
4. **Reduce complexity** — with 40 tasks and 7 goals, the system says *this is what
   matters now* (one Main Quest/day, one WHAT NOW recommendation).
5. **Never fake capability** — no pretend bank sync, phone monitoring, or AI when the
   provider is down; honest disabled/offline states everywhere (Part 46/61/72).
6. **Anti-drift** — detect busy-work vs. Main Quest movement, intervene with evidence.
7. **Privacy first** — finances, journal, health, people data never auto-shared.

## Day-to-day surfaces (target UX)

- **TODAY**: Main Quest (one), 3–5 Daily Missions, Side Quests, Non-Negotiables,
  WHAT NOW?, streak, weekly progress, coach insight.
- **Morning Start** (fast, optional): state check → Why reminder → standing → Main
  Quest proposal → non-negotiables → day plan → START DAY.
- **Night Review** (2–4 min): completed/missed/why, wins, lesson, gratitude,
  tomorrow's One Big Thing → auto-draft of tomorrow.
- **COACH**: chat with tools + memory; Brain Dump → structured suggestions.
- **PROGRESS**: XP, attributes, goals pace (ahead/on-track/behind), reviews.
- **SOCIAL** (Phase 4): people, accountability, clubs.
- **ME**: character, level, titles, North Star, settings, memory controls.

## Life framework the AI protects

BODY (train/sleep/eat/recover) · PURPOSE (know what & why) · PROGRESS (meaningful daily
movement) · PEOPLE (protect relationships) · MIND (control the controllable, reflect) ·
CHARACTER (keep promises, take responsibility).

## Audience & tone

Adults building a serious life; 70% premium life app, 20% game, 10% manga energy.
Default light/white UI, purple identity color. Original IP only (Part 57).

## Specced forward features (addendum, with phase tags)

- **Minimum Day** (P2): on bad days the app proposes one minimum action for
  Body / Progress / People / Mind — "protect these and call it a successful
  recovery day". The app never collapses because a week did.
- **Comeback Quest** (P2): after N days away — no guilt; 3 missions (what
  changed → choose one priority → one Main Quest) + comeback XP. Returning is
  part of the game.
- **Life Experiments** (P2/P3): 14-day A/B tests on the user's own behavior
  (baseline → experiment → measured result → "add to Playbook?"). MAINXP tests
  advice instead of only giving it.
- **Personal difficulty** (P2): Easy/Normal/Hard/Boss/Legendary per quest,
  calibrated to the person (5 km can be Legendary for one user, Easy for
  another); difficulty affects XP through the ledger multiplier.
- **Non-monetary rewards** (P2): the reward catalog suggests rest, a movie, a
  hike, a social evening — not only purchases, especially when Wealth is a goal.
- **Daily Wisdom** (P3): situation-matched curated quotes (stoicism, discipline,
  business…) + "APPLY IT" prompt. Curated, source-aware library only; never
  imply a living figure personally coaches the user.
- **Challenge generator** (P3): the coach turns an observed weakness into a
  bounded game ("7-DAY ATTENTION RESET", "5-DAY REVENUE SPRINT") with XP and a
  badge.
- **Seasons with endings** (P2/P3): a season has start/end dates, one main
  objective, protected priorities, deliberate deprioritizations — and a SEASON
  COMPLETE review with results, lessons and the next season. Life gets chapters.
- **My Journey timeline** (P3): first Main Quest, first level-up, first 5K,
  setbacks, comebacks — emotionally powerful after a year.
- **Year in Review** (P3): the year in verified numbers + titles earned +
  character transformation; shareable.
